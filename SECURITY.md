# Security Policy

## Supported Versions

Only the latest release gets security fixes.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

Report a vulnerability in a private security advisory:
[report a vulnerability](https://github.com/pushkar-anand/jocasta/security/advisories/new).
Do not open a public issue.

Give the version, how you run Jocasta, the steps to reproduce and the impact.

I reply in the advisory within 7 days.
Until the report is closed, I post an update there at least once a week.

If I accept the report, I release a fix and publish the advisory.
The advisory credits you, unless you ask me not to.
If I decline the report, I explain why in the advisory.
